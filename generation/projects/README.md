# Projects

Project-specific generation notes live here, one file per project, once Daniel confirms rules that apply only to that project.

This folder starts empty. Do not copy client or project notes from the editing wing. Do not add a file for work that has no confirmed generation brief. Do not paste the locked standing generation benchmark, or the from-scratch generation benchmark, into a project file. Name them and point at the lock outside this repo.

When a project file is added, read it after `scene-design.md` and `workflow-and-qc.md`, and before the general look and audio files.
