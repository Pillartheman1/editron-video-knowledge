# Assets

Reusable generation assets live here: HDRIs, materials, rigs, and other files a later job is allowed to reuse.

This folder starts empty. Do not add a file until its source and license are recorded beside it. A file whose license is unknown stays out. Do not place ripped sound libraries, unlicensed character models, or anything taken from the editing wing here.

An asset is not a style rule. Using it still has to match the locked prompt, and a character asset still has to be the same model on every frame (`scene-design.md`).
